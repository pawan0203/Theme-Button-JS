# 🌙 Theme Toggle Button (Light/Dark Mode)

A simple and responsive theme toggle button that allows users to switch between **Light Mode** and **Dark Mode**. This project is built using **HTML, CSS, and JavaScript**.

---

## 🚀 Features

- 🌞 Light Mode and 🌙 Dark Mode support
- 🔄 Toggle button to switch themes
- 💾 Saves user preference using `localStorage`
- 📱 Responsive design
- ⚡ Smooth transitions between themes
